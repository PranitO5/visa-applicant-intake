# Visa Applicant Intake (concept prototype)

A clickable concept for a document-first work visa intake experience, designed from the applicant's point of view.

**The idea:** applicants upload their passport, degree certificate and offer letter first. The system reads them and fills in most of the questionnaire, so the applicant checks details instead of retyping them. Every filled-in value shows which document it came from, and the applicant stays in control of every answer.

## What to try
1. Start with documents, then use the sample documents.
2. On "Check details", choose how the name should appear and click a document tag to see where a detail came from.
3. The date of birth is filled in wrong on purpose. See whether you catch it.
4. Open **Design notes** (top right) for the reasoning behind each screen and the session log.
